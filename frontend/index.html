SECURITY AWARENESS

Password Security Best Practices

🔑

Use unique passwords

Avoid using the same password across multiple accounts. A compromised password can otherwise affect several services.

📐

Prefer longer passwords

Longer passwords or passphrases generally provide a larger search space for attackers.

🚫

Avoid predictable patterns

Names, birthdays, keyboard sequences and simple number patterns are easier to guess.

🔐

Use a password manager

Password managers can help generate and securely manage unique passwords for different accounts.
